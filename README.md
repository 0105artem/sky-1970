# Небо Елены

Статический сайт-подарок. Сборка не нужна: `index.html` + папка `assets/`.

## Как выложить на GitHub Pages

1. Создайте на github.com новый публичный репозиторий (например, `nebo`).
2. Загрузите в него `index.html` и папку `assets/` целиком (Add file → Upload files, перетащить оба).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Не переименовывайте и не удаляйте репозиторий после печати QR-кода.

## Что можно поменять

- **Время рождения**: `assets/app.js`, строка `var BIRTH_TIME = null;` → например `'07:30'`. Появятся асцендент, дома и отдельный экран про асцендент.
  Посмотреть заранее без правки файла: добавить к адресу `?t=07:30`.
- **Поздравление и подпись**: `index.html`, блок `data-s="wish"` в самом конце (текст в `wish-t`, подпись в `sign`).
- Позиции планет посчитаны по Swiss Ephemeris и лежат в `assets/data.js`; править их не нужно.
